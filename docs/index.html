剣道・居合道でいう「後の先」とは

先に動いた相手の「確定した軌跡」を読み、相手が引けなくなった瞬間に最適な反撃を繰り出す——剣術の極意が、強化学習エージェントの学習過程で自発的に出現するかどうかを検証します。

先の先（せんのせん）
先に動く。高リスク・高リターン。ハチドリの奇襲潜航。
後の先（ごのせん）
相手がコミットした後に仕掛ける。チーターの転換後捕捉。
先々の先（せんせんのせん）
相手の意図を先読みして先手。最高難度の予測戦略。

🐸 ゆでカエル、になっていませんか？

自然界には「現状維持バイアス」は存在しません。すべての生物は毎瞬間、最適な意思決定を学習し続けています。地域経済の停滞を「ゆでカエル状態」と捉え、自然界の攻防戦から生存戦略を学ぶ——そのきっかけとなるシミュレーションです。
